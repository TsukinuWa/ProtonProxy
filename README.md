## ⚙️ How it works

Proton Proxy is a focused Firefox add-on for reaching Proton through a proxy when the direct route is slow, filtered or blocked. It wraps the connection in HTTPS, masks the server side of the request and monitors availability so that new interruptions are noticed early instead of on your next login attempt.

Open Proton in a tab, sign in and keep working — the extension stays free, keeps configuration to a minimum and does not add extra steps to the flow.
